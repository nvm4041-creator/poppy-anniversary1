# หนึ่งเดือนของเรา ♡

Static mobile-friendly anniversary page for Poppy. The images are kept beside `index.html`, so the page works without a build step.

## Publish with GitHub Pages

This repository's GitHub Actions workflow publishes the site. In **Settings → Pages**, select **GitHub Actions** as the source if it is not selected already.

When publishing completes, GitHub shows the site URL in **Settings → Pages**. For a repository named `poppy-anniversary`, the URL is usually `https://<your-github-username>.github.io/poppy-anniversary/`.

The four photos are part of the public site and can be viewed by anyone who has the link.
